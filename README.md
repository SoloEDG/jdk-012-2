# 余境 · 虚拟艺术馆

安装：`npm ci`

本地启动：`npm run dev`

Docker 启动：`docker compose up --build`，访问 http://localhost:18112 。

## 漫游影片

左侧「漫游影片」页签可把一次参观录成可重新剪辑的影片：

- 录制保存行走轨迹、转向、作品切换、讲解与收藏标记（稀疏关键帧 + 精确事件，不逐帧存画面）。
- 回放由同一时间位置驱动镜头、字幕与作品介绍；回放不计入真实参观统计与收藏。
- 剪辑支持剪掉走廊空白时段、删除/上移/下移片段、撤销与还原；跨片段镜头自动绕开墙体，讲解只在其所属片段内播放。
- 原始记录与当前剪辑版本保存在本机（localStorage `yujing-film-v1`），刷新后恢复。
